# 🚀 Barakat Dev Portfolio

A modern and high-performance portfolio website built by Mostafa Barakat.

## 🌍 Features

- ⚡ Built with Nuxt 3
- 🎨 TailwindCSS modern UI
- 🎬 GSAP animations
- 🌍 Bilingual (Arabic / English)
- 📱 Fully responsive
- 🚀 Optimized for SEO

## 🧠 Tech Stack

- Nuxt 3
- Vue 3
- TailwindCSS
- GSAP
- Laravel (API)
